# PDF Portal Editor Privacy Policy

Effective date: 2026-11-17

This policy covers PDF Portal Editor, published by MindtheApp.

PDF Portal Editor does not collect usage data, analytics or telemetry. It has no accounts, no advertising, no usage tracking and no crash reporting. Your documents are never sent to us. The app has an optional feedback window: only if you write a message and press Send does anything reach us (see "Feedback and reviews" below).

## Your documents stay on your PC

PDF Portal Editor opens, reads, edits and saves your files on your own computer. It never uploads your documents, and we have no servers that receive them. Tools that produce a result save it as a file on your PC, by default under a new name so your original is kept.

## Data that stays on your PC

- Your settings and the list of recently opened PDFs (file names and the page you stopped at), so you can pick up where you left off.
- Your saved signatures, stamps and other items you create in the app.
- The start date of the Pro features trial, in a small file in the app's data folder.
- If something goes wrong, a short error note in a log file in the app's data folder. It is never sent anywhere.
- When you last saw the review card and your choices about it, in the app's settings file.
- A feedback message that could not be sent yet (see below).

This data is stored in the app's own data folder on your PC. None of it is sent to us, except a feedback message you chose to send, and uninstalling the app removes it.

## Feedback and reviews

Now and then the Store version of the app may show a small card asking for a Store review or for feedback. It never appears in the first 3 days, and not more often than every 4 days. "Not now", "Don't ask again" and the File menu setting "Ask me for a review now and then" stop it. A Store rating is handled by the Microsoft Store.

When you press Send in the feedback window, these go to our feedback service, Sentry (Functional Software, Inc., EU data region), in a project used only for PDF Portal:

- the message you wrote, with file and folder paths and your Windows user name removed first;
- the kind of message you chose (idea, problem, question or praise);
- your e-mail address, only if you typed one, used only to reply to you;
- a picture, only if you chose one; its text, location and date information is removed first;
- the app name, version and channel (Store or portable), a random ID for the message, the Windows version and the .NET version.

No documents, file names, logs, settings, user name, PC name, installation ID or device details are sent. Nothing is sent unless you press Send.

Like any internet connection, the feedback service sees your IP address while the message is delivered. We do not use it to identify or locate you.

If a message cannot be sent (for example while you are offline), it is kept as plain text, with any picture you chose, in the Feedback folder in the app's data folder, and sent automatically the next time the app starts. To remove it, delete the files in that folder or uninstall the app.

Feedback is kept for the period set by our feedback service plan and then deleted automatically. To have a message deleted sooner, email us (see Contact).

## Pro features and the Microsoft Store

Pro features is a one-time purchase handled entirely by the Microsoft Store. The app asks Windows whether you own it. We receive no payment details and no personal information from the purchase.

## Links, read aloud and text recognition

- A link inside a PDF is only opened after you confirm, in your default browser or mail app; that app then handles the request.
- Read aloud uses the speech voices installed in Windows.
- Text recognition (OCR) runs on your PC. Windows may download its own recognition files the first time it is used.
- When the text editor cannot find a font on your PC, it offers "Get it from Google Fonts". Only if you click it, the app downloads that font from Google Fonts (fonts.googleapis.com) and its licence from Google's font repository on GitHub (raw.githubusercontent.com). The request contains the font's name and nothing from your document; like any web request, Google and GitHub receive your IP address. The font is saved in the app's data folder.
- Dictation buttons start Voice Portal, a separate app, if you have it installed. They send nothing themselves.

## Children

The app is not directed at children. It collects no personal information, except what someone chooses to put in a feedback message.
